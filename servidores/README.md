# Servidores y servicios

Máquinas virtuales y servicios que corren sobre la red.

- `entorno-virtual/`: configuración del entorno de máquinas virtuales
- `active-directory/`: servidor Windows, dominio, departamentos, usuarios, grupos y carpetas compartidas con permisos
- `copias-seguridad/`: política de backups y scripts
- `capturas/`: evidencias de la configuración
