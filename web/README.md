# Web con Astro

Sitio web de la empresa hecho con [Astro](https://astro.build).

## Crear el proyecto

Desde esta carpeta:

```bash
npm create astro@latest sitio
cd sitio
npm install
npm run dev      # servidor local
npm run build    # genera dist/ para publicar
```

`node_modules/` y `dist/` no se suben a Git.
